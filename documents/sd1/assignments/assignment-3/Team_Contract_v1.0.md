## Project Scope

Pulse is a modular IoT communication system for farm sensor data. The first release sends one test sensor reading from an ESP32-S3 field device to a Linux hub.

The team uses a custom sensor driver and the purchased ESP32-S3 hardware. The project does not include a dashboard or Windows support in the first release.

## Communication

- Use email/messages group for daily team communication and advisor messages.
- Use repository issues and pull requests for formal work records.
- Reply to normal messages within 24 hours on weekdays.
- Mark an urgent message clearly and notify all affected members.
- Record design decisions in the repository.

## Meetings

- Meet with the advisor on Monday, Wednesday, and Friday during active project weeks.
- Send a short agenda before each planned advisor meeting.
- Record the date, attendees, decisions, action items, and open questions.
- Hold an additional team meeting when a deadline or blocked task requires it.
- Tell the team before a missed meeting when possible.

## Work and Quality

- Assign each task to one owner with a due date.
- Tell the team when a task is at risk.
- Review code before it enters the main branch.
- Add tests for new behavior when the behavior can be tested.
- Keep project documents current with the implemented design.
- Track shared equipment purchases against the $1,000 budget.
- Split approved project costs among the three team members.

## Decisions

1. Present the decision and its reason to the team.
2. Discuss technical, schedule, cost, and user effects.
3. Use consensus when possible.
4. Use a majority vote when the team cannot reach consensus.
5. Ask the advisor to resolve a technical tie.
6. Record the final decision and its reason.

## Conflict Process

1. Discuss the concern directly and promptly.
2. Bring an unresolved concern to the full team.
3. Ask the advisor to help with an unresolved project concern.
4. Ask the course coordinator to help with a course or policy concern.
